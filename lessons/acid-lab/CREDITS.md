# Credits

Everything in the Acid Lab is made in code for this project: the bench, glassware, test papers, pH meter, class
board and sounds. There are no third-party models, images or sounds, so there is nothing to licence or credit
beyond the project's own licence. three.js (MIT) is loaded from jsDelivr, as in every lesson.

The pH values are typical textbook figures for each substance (real samples vary a little). Litmus changes colour
between about pH 4.5 and 8.3; the universal indicator colours follow the usual school colour chart.
